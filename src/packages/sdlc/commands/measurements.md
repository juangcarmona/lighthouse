# Delivery measurements

Read the [measurement contract](../measurements.md). Inspect versioned formulas with `lighthouse-sdlc measurements definitions`. Derive the report from a retained repository/window bundle using `lighthouse-sdlc measurements derive --input frozen.json`.

Report each metric's status, numerator, denominator, coverage, censoring and source links. Offline integrity does not establish live source authenticity. Keep missing fields unknown and preserve historical source revisions. This command performs no network request or policy mutation.
