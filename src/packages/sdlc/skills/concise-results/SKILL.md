# Concise public results

Use this when writing `effect.body`. Write two or three plain sentences: what changed or was established, the blocker if there is one, and the next action. Name the exact PR or issue when known. Keep commands, check results, links and uncertainty accurate. Put detailed evidence in `result.output` and the run artifacts.

Read the draft once before returning it. Remove filler, repeated stage names and claims that the evidence does not support.
