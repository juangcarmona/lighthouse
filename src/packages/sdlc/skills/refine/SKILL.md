# Refine

Turn a triaged item into a problem that can be designed.

## Steps

1. Read the triage record, product context and relevant architecture evidence.
2. State the problem, affected users, constraints, acceptance criteria and explicit out-of-scope work.
3. Resolve or record dependencies, risks, assumptions and missing evidence.
4. Check the Definition of Ready and return the evidence that supports each check.
5. Stop at the `ready` gate and name the next decision.

## Completion

The work item has a bounded problem statement, testable acceptance criteria, resolved owners for open dependencies and a Ready decision.
