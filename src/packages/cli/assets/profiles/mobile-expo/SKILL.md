# Lighthouse Expo mobile profile

Read the mobile profile guide before changing an Expo adopter.

Keep features aligned with product capabilities and use TanStack Query for server state. Keep credentials in secure storage and declare every permission and deep link.

Treat Android and iOS behavior as native evidence. Add web export only when the product selects it and keep that evidence separate.

Run Expo doctor, typecheck, tests and the selected emulator or device journey after a focused change.
