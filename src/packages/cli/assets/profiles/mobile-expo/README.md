# Lighthouse Expo mobile profile

Use this profile when Android or iOS is a real product requirement and the application will run as an Expo and React Native app.

## Start here

| Need | Read |
| --- | --- |
| New mobile application | [adoption](adoption.md) → [guardrails](guardrails.md) → [testing](testing.md) |
| Add a native capability | [guardrails](guardrails.md) → [testing](testing.md) |
| Export a web build | [adoption](adoption.md) → [testing](testing.md) |

## Defaults

Use Expo, React Native, Expo Router, strict TypeScript, TanStack Query and secure storage.

Declare deep links, permissions, push notifications and native build targets before implementing a platform capability.

Treat web export as an explicit selection with separate evidence. Do not make Expo a hidden layer on top of a React web profile.
