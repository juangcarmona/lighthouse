01 / DELIVERY BUNDLE

What Lighthouse hands over.

Adoption leaves a project with the code, rules, tools, workflows and evidence needed to keep moving.

01

Code

The application remains the adopter's work. Lighthouse gives it predictable boundaries and selected profiles.

02

Conventions

Repository, stack and interface rules, with hard checks where the rule can be verified.

03

Harness

A versioned CLI and package contract that initializes, reconciles and verifies the baseline.

04

Workflows

The SDLC package, commands and agent guidance that move bounded work through its stages.

05

Health

Evidence from guardrails, projections and authority checks, with failures and gaps reported plainly.

Lighthouse owns the baseline and its evidence contract. The adopter owns the product, its decisions and the code that delivers it.
