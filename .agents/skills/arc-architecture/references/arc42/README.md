## How to use the references

- Start from the requested change, evidence area, or architecture question and select only matching section references.
- Each section README gives a purpose, subsection map, evidence leads, gap/conflict handling, practical guidance, and source links.
- Treat repository evidence as evidence of observed behavior, not automatically as intent. Mark inference and ask the maintainer about unresolved intent, missing priorities, or conflicting sources.
- Follow the project’s chosen arc42 adaptation; do not add empty sections merely to match the template.
- Section folders are extension points. Add focused Markdown documents for topics that need more detail and link them from that section README.
