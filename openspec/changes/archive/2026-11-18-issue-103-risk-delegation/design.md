# Design

The existing trusted host supplies repository, issue, route, source, intent and policy identities. A small provider-neutral evaluator returns a restrictive decision with the separate assessment axes, exact reviewed paths, reasons and next action. Its result grants no effects. The actual adapter retains these decisions in its report and command-evidence member.

Refinement names exact candidate paths and relevant dependents. Project stop paths apply both to declared scope and the actual diff, including host-owned planning artifacts. A candidate can use a subset of admitted files; scope growth needs fresh refinement. FF's independently validated issue-bound OpenSpec planning root remains an explicit host exception, with sensitive-path rules still applied.

Candidate assessments enter the independent review binding. Publication additionally requires actual host check exits/execution states and that fresh review. Current source, owner intent and reservations are rechecked through the existing callbacks before effects. Planning and implementation repairs share the existing correction budget. Historical policy and report formats remain supported when the option is absent.
