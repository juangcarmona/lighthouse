# Proposal

<!-- pdac-scope: cited -->

## Why

Confined planning workers can read retained Product Change drafts but cannot compose their structured files without retranscribing their contents. A deterministic selection operation repairs bounded, resumable preparation without expanding general execution permissions.

## What Changes

- Discover hash-bound retained draft objects in admitted task inputs and expose inspection and complete-candidate composition through a narrowly scoped local tool.
- Require explicit latest-per-path selection or omission, current request/source/baseline/schema binding, and existing candidate limits.
- Atomically write only the authorized envelope, leaving provider validation, product approval, apply, publication and continuation with their existing owners.
- Ship synthetic regressions, a patch changeset, and installation/native-qualification guidance.

## Capabilities

### New Capabilities

- `retained-product-composition`: Deterministic selection of admitted retained draft objects into a complete prepared candidate.

### Modified Capabilities

None. The existing four OpenSpec capabilities cover unrelated issue control, command scratch, source links and CI waiting. The accepted product requirements already authorize this bounded preparation correction; no product-model change is needed.

## Impact

The SDLC package owns the composition contract, fixed-path local tool, adapter integration and worker guidance. Existing small literal candidates and stage-result consumers remain supported. No model selection, deadline, concurrency, credentials, resource ownership, provider validation or downstream approval rule changes.

## Product authority

This corrects bounded/resumable preparation under FR-PRODUCT-CHANGE-WORKFLOW and UC-PREPARE-PRODUCT-CHANGE. BR-PRODUCT-CHANGE-HANDOFF preserves provider ownership, exact-delta approval, apply and single continuation; BR-AGENT-LAUNCH and QR-AGENT-ISOLATION preserve explicit scope and run isolation. Direct neighbours BR-ENTRY-AUTHORITY, BR-HUMAN-AUTHORITY, BR-FAIL-CLOSED, BR-BOUNDED-WORKFLOW and BR-WORKFLOW-STATE remain unchanged. No accepted model gap was identified. No domain lifecycle is defined for retained composition; existing delivery state and approval rules are preserved, not replaced by an invented lifecycle. Broad behaviours SB-SDLC-GATES and SB-CHANGE-FLOW-VERIFIED constrain honest evidence and continuation; composition regressions cover only their applicable preparation boundary, not the entire delivery journey.
