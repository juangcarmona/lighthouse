# Proposal

<!-- pdac-scope: cited -->

## Why

Instruction growth in refinement and implementation is not measured against explicit branch selections. Reproducible fixed-input budgets make that growth reviewable without claiming token savings or weakening workflow obligations.

## What Changes

- Inventory four existing refinement/implementation branches with selected references, UTF-8 byte totals, SHA-256 identities and explicit caps.
- Add offline verification and deterministic failure fixtures to ordinary Node test discovery.
- Bind supported selections to complete entry and transitive sources, refusing unreviewed instruction-context changes even when inventory observations are refreshed.
- Distribute the module, inventory and schema through additive SDLC exports, with a real packed-consumer check.
- Explain coverage and preserve all existing instructions, decisions and evidence access; no instruction reduction is planned.

## Capabilities

### New Capabilities

- `instruction-budgets`: Reproducible bounded instruction measurements and fail-closed inventory verification.

### Modified Capabilities

None. The installed OpenSpec capability inventory has no existing instruction-budget capability.

## Impact

SDLC package assets, two entry skills, repository check script, package tests and a patch changeset. No new dependency, root verification command, runtime service, provider authority or user-facing view changes.
