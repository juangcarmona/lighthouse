## Decisions

Use the canonical read-only fact collector for both preflight and source admission. Each Refine/Propose assessment reports installed contract, write authority, repository policy, source reservations and stage evidence. Evidence skipped after an earlier denial remains unavailable with `earlier-prerequisite-not-met`; direct owner entry is not a fabricated triage result. Existing eligible/availability/reason fields remain compatible.

Keep current request IDs, payload binding, durable claims, source aliases and validated worker outcomes. Ordinary comments remain input; Continue requires the exact current question and original grant. The consumer reads facts from the public SDK and does not copy source policy.

## Verification

First reproduce absent prerequisite observations in focused tests. Exercise missing/denied authority, disabled policy, unsupported capability, incomplete reservation coverage and direct owner entry. Run full source verification and clean public-package installation. Reconcile historical proposal failure from its retained log and result artifact without replaying its consumed attempt. Qualify actual connected-user operation separately from fixtures.

## Recovery

The additive assessment fields require no migration. Revert their source change and the consumer display together if necessary. Retain source receipts and the private consumer journal; rollback never resends an uncertain request.
