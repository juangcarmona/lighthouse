type: structured-behaviour
title: Resolve and apply a semantic initialization plan
status: draft
illustrates: [UC-INITIALIZE-PROJECT]
given:
  - An adopter has described a project and may or may not have a reference project.
  - The initialization skill can read the installed profile catalog.
when: The agent prepares a plan and the adopter invokes plan-driven initialization
then:
  - The plan records the intent, resolved application choices, optional reference metadata and question status.
  - A dry-run reports the deterministic local operations and conflicts without changing the target.
  - An explicit apply with no unresolved questions creates only the selected owned surfaces.
  - Unsupported or ambiguous choices stop before writing and report a repair action.
uses-terms: [TERM-INITIALIZATION-PLAN, TERM-FOUNDATION, TERM-PROFILE, TERM-ADOPTION]
---

## Intent

Establish that semantic project requests become reviewable and deterministic initialization work without requiring a reference project.

## Boundaries

This example does not assert that application source code, ProductShape, ArcShape or remote provider resources are generated by the initializer.
