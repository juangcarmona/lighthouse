## Definition

An upgrade guide is the versioned adopter-facing route for moving a Lighthouse foundation or declared integration from one supported contract to another.

## Distinguish From

An upgrade guide is not a release note, an unreviewed copy operation or a replacement for the machine-readable upgrade plan.

## Usage

An upgrade guide states prerequisites, current and target contracts, affected scopes, ordered steps, expected evidence, verification, conflict handling and recovery for the update it owns.
