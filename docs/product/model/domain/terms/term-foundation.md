## Definition

A maintained set of reusable project starting points, conventions, tools and verification contracts
that an adopting repository can use without becoming a framework runtime.

## Distinguish From

A foundation is not the product being built, an application framework, a hosted service or a
factory runtime.

## Usage

Lighthouse is the foundation consumed by adopting software projects.
