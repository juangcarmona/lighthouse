## Definition

A hotfix route is an expedited delivery route for a confirmed defect that uses triage, a bounded implementation, verification, integration and review without requiring a full feature proposal.

## Distinguish From

A hotfix is not a bypass around scope, verification, authority or release decisions.

## Usage

The route requires an impact statement, a rollback or containment plan and a visible reason for the expedited path.
