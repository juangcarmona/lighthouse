## Definition

An upgrade plan is the deterministic, reviewable description of a proposed Lighthouse or integration update before it writes to an adopting project.

## Distinguish From

An upgrade plan is not an applied migration, a package version alone or a semantic interpretation of issue prose.

## Usage

An upgrade plan reports the independent version dimensions, prerequisites, selected scopes, ownership evidence, change classifications, preserved content, conflicts, verification and recovery information for the proposed update.
