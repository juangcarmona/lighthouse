## Definition

A project-owned composition of lifecycle contracts, tool integrations, agent execution contracts, guardrails and evidence that helps an adopter deliver software changes through a declared route.

## Distinguish From

A delivery harness is not a product authority, architecture authoring system, agent model router, memory provider or factory runtime.

## Usage

Lighthouse is the delivery harness that connects ProductShape, ArcShape, OpenSpec and the selected agent host while each system keeps its own source of truth.
