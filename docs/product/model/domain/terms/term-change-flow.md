## Definition

A bounded route that carries one admitted project change from clarified intent through its declared artifacts, implementation evidence and review outcome.

## Distinguish From

A change flow is not a product roadmap, a provider-specific agent session or a promise that every stage runs automatically.

## Usage

Lighthouse describes a change flow that can run through OpenSpec and can fall back to a manual route while preserving the same evidence and decisions.
