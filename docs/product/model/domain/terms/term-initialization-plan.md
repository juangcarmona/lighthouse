## Definition

A versioned, reviewable declaration of the project intent and resolved choices that an initializer can validate and apply deterministically.

## Distinguish From

An initialization plan is not an agent transcript, a reference project, a generated application implementation or permission to perform external writes.

## Usage

An agent creates or refines the plan and Lighthouse validates it; a plan-driven initializer previews its local operations by default and requires explicit apply authorization.
