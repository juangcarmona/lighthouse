## Responsibility

Provide a reusable, adoptable delivery bundle that helps a project start consistently and keep its engineering expectations, delivery workflows and health evidence visible and verifiable.

## Language

The context defines foundations, delivery bundles, profiles, adoption, guardrails, managed projections, integrations, lifecycle stages and verification as reusable project capabilities. Product and architecture meaning remains in the authorities that own those concerns.

## Boundaries

The context covers initialization, baseline content, deterministic tools, technical profiles, visual conventions, lifecycle contracts, agent execution contracts and adoption evidence. It excludes hosted factory operations, product modelling, architecture authoring, agent runtime infrastructure and deployment ownership.

## External Relationships

ProductShape supplies product intent when adopted. ArcShape supplies architecture documentation when adopted. OpenSpec supplies change-artifact mechanics when adopted. A factory or other integrating system may compose and operate the foundation for new projects. Agent workflow hosts consume its instructions and tools, while Lighthouse supplies provider-neutral run, memory and handoff contracts. An adopting project owns its product code and project-specific decisions.
