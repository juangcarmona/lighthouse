## Definition

The discoverable description of a tool's owner, purpose, inputs, outputs, permitted side effects, evidence and failure behavior.

## Distinguish From

A tool contract is not an implementation package, provider binding or permission to change another system's managed files.

## Usage

Lighthouse uses tool contracts to assemble its harness while ProductShape, ArcShape, OpenSpec, Git and agent hosts retain their owned mechanics.
