## Purpose

Provide the environment in which an AI agent consumes Lighthouse guidance and invokes its tools.

## Goals

Make the same repository rules and verification evidence available to agents and people.

## Responsibilities

Read project-owned instructions, invoke supported tools and report their results without claiming
human decisions.

## Boundaries

The agent host cannot extend the project's declared scope, approve product or architecture
decisions, merge changes or release software on the foundation's authority.
