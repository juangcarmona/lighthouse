## Purpose

Use the foundation to start or improve a software project with a known baseline.

## Goals

Obtain a working project structure, select only the profiles it needs and understand the checks
that govern its repository.

## Responsibilities

Run initialization and verification, own project-specific decisions, review managed changes and
record justified exceptions.

## Boundaries

The adopter does not treat Lighthouse guidance as a substitute for product intent, architecture
evidence or human acceptance in the project.
