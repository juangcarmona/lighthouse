## Definition

An adoption release is a reproducible set of versioned package artifacts and verification evidence intended for a known adopter before public publication.

## Distinguish From

An adoption release does not promise registry availability, long-term compatibility or a hosted Lighthouse service.

## Usage

An adopter consumes the exact artifacts produced by Lighthouse's release pipeline.
