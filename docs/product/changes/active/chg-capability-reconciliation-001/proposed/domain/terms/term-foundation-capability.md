## Definition

A foundation capability is a selectable Lighthouse contract with a declaration, prerequisites, owned projection, verification method, mutation boundary and adoption evidence.

## Distinguish From

A capability is not a tracker label, a package version or a provider-owned source of truth; a capability may use any of those surfaces through an explicit integration.

## Usage

The first capability adapter reconciles the declared tracker label vocabulary. Future adapters may use the same declaration and plan contract for hooks, CI, guardrails or profiles.
