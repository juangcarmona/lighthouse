# Lighthouse visual system

The independent UI package distributes [`DESIGN.md`](../../src/packages/ui/DESIGN.md) for humans and agents; [`tokens.css`](../../src/packages/ui/tokens.css) is the machine-readable source of truth.

During `init`, Lighthouse can install this package, create the adopter's design skill and add a deterministic token verifier when the selected stack supports one.

The gallery is an executable reference for maintainers and is not automatically distributed to adopters.

Use the package guide for token roles, appearance, component semantics, accessibility, motion, elevation and ownership. Use [`adoption.md`](adoption.md) for the repository-level adoption route and [`src/gallery/index.html`](../../src/gallery/index.html) for the executable composition example.
