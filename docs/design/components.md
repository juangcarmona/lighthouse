# Semantic component recipes

The component recipe contract is described in [`DESIGN.md`](../../src/packages/ui/DESIGN.md) and implemented by [`components.css`](../../src/packages/ui/components.css). The recipes use native elements, semantic tokens and accessible states; products keep their own behavior, routing and domain components.

The gallery markup in [`src/gallery/index.html`](../../src/gallery/index.html) is the executable composition reference. Run the repository visual checks before changing a recipe.
