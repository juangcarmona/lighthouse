# 12. Glossary

| Term | Meaning |
| --- | --- |
| Adopter | A project that consumes Lighthouse guidance or packages |
| Baseline | The versioned set of Lighthouse checks, packages and guidance |
| CLI | The Node command in `src/packages/cli/` |
| Managed projection | A generated file whose source is another declared artifact, such as `LIGHTHOUSE.md` |
| Profile | A selectable set of stack-specific source, checks and guidance |
| ProductShape | The product-intent authority when a project adopts it |
| ArcShape | The architecture-documentation authority when a project adopts it |
| OpenSpec | The change-artifact tool configured in this repository |
| Reference profile | Example source and checks that demonstrate a contract without defining production infrastructure |
